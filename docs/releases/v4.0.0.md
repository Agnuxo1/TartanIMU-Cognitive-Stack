# v4.0.0 release notes

Release date: 2026-09-23.

## What changed

- Enforced per-run worker-call, tier-call, token-start, and JEV-checkpoint
  budgets through Luna → Sol → Astra escalation.
- Added local Luna-first routing when initial JEV routing is unavailable or
  there is no route checkpoint budget.
- Connected the reflex value-of-information signals (risk, uncertainty,
  conflict, failure, irreversibility, phase change) to event-driven supervision.
- Added the missing typed JEV deliberation question set and kept optional
  thinktank views at Luna tier followed by a Sol critic.
- Added data-minimizing telemetry and regression tests for budget enforcement,
  JEV deliberation, and redaction.
- Included the TartanIMU synthetic contract suite in pytest and CI.
- Preserved prior curated versions under `versions/`.

## Verification in the packaged workspace

The Windows Python 3.13 virtual environment on E: ran the full test suite:
  **60 passed**. `compileall` passed for the runtime and both test/source trees.
These are software checks only. They do not verify a Kaggle account, train or
evaluate a competition model, or establish a contest rank.

## Known boundaries

- No challenge-authorized dataset, fitted model, model weights, prediction CSV,
  or organizer score-service result is included.
- The TartanIMU module implements synthetic input/split/score contracts, not
  the official trajectory evaluator.
- Runtime token limits prevent starting additional requests after observed
  usage reaches a cap; individual provider calls are not server-side hard-capped.
