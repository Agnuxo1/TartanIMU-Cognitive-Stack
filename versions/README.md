# Preserved versions

The `v2.0.0` and `v3.0.0` directories are curated source snapshots retained
to preserve the project's evolution. They are historical references, not the
recommended runtime. The current supported implementation is at the repository
root (`VERSION` = 4.0.0).

Historical copies have been scrubbed of the local machine's paths and account
labels before publication. For comparisons, review the corresponding release
notes and tests. Do not import code from an older snapshot without re-running
the current security, budget, and test checks.
