# JEV Orchestrator 2.0.0

This release turns the repaired runtime into a reusable cognitive control
plane:

- deterministic work is attempted before every LLM route;
- Luna is always the first LLM worker;
- JEV supervises on state-changing events and bounds retries;
- second opinions and thinktanks require evidence-based triggers;
- Sol receives either compact factual continuation context or a clean restart;
- Astra remains the final escalation tier;
- model IDs, provider quotas, decisions, costs, and gate outcomes are audited;
- credentials and raw local telemetry stay outside the public source surface.

The `v1-recovered` tag remains available as the preserved baseline snapshot.
The `v2.0.0-advanced` tag identifies this release.
